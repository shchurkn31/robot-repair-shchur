18.10.2026 — Юніт 4: вороги і снаряди
Що зроблено: Реалізував патрулювання ворога, стрільбу снарядами та механіку ремонтного влучання з викликом Fix().

Що не вийшло або забрало найбільше часу: Пошук прихованих NullReferenceException через незакріплені компоненти в Inspector та відсутній Animator Controller.

Що зрозумів про Animator, шари й Awake: Awake() виконується першим для швидкого пошуку компонентів через GetComponent; Animator обов'язково вимагає наявний контролер; шари керують рендерингом та фізичною взаємодією.

Які Speed і Change Time обрав і для якого гравця: Speed = 3.0 та Change Time = 3.0 для передбачуваного руху ворога, що балансує зі швидкістю гравця 3.0.

Що робить мій снаряд з ворогом і як це пасує до моєї рамки: Снаряд лагодить робота й вимикає його фізику (simulated = false), що ідеально пасує до миролюбного сюжету гри про допомогу.

Що робитиму далі: Створення UI (інтерфейсу) для показу шкали здоров'я та діалогів з персонажами.
